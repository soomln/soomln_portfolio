# PROJECT 04 — CHARWELL 버번 브랜드 프로모션 웹페이지 기획서

작성일: 2026-11-20 · 상태: 기획 확정, 디자인 시작 전

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트 | 가상 버번 위스키 브랜드 **CHARWELL**의 프로모션 랜딩 페이지 |
| 형태 | Figma 디자인 → **실제 코드로 구현한 웹페이지** (상세페이지 이미지가 아님) |
| 화면 | 데스크톱 1440 + **모바일 390** (이번 프로젝트부터 반응형) |
| 역할 | 기획 · 카피 · 이미지 합성 · UI 디자인 · 퍼블리싱 |
| 도구 | Figma, Photoshop, Gemini(이미지 생성), HTML / Sass / 바닐라 JS, WebGL |

### 왜 웹페이지인가
포트폴리오의 02·03이 모두 860px 상세페이지라서, 04는 **웹 레이아웃 + 인터랙션 + 반응형**을 보여 주는 작업으로 다양성을 만든다.

### 왜 버번 · 불인가
- 버번은 법적으로 **안쪽을 불로 그을린 새 오크통**에서 숙성한다 → 브랜드 키워드 **"불"**.
- 포트폴리오 사이트의 **WebGL 연기 배경**을 호박색으로 바꿔 재활용 → 내 기술과 주제가 이어진다.
- **숯불 고기 + 버번**은 미국 바비큐의 정석 조합 → 고깃집에서 일한 경험을 페어링 섹션에 녹인다 (면접 이야깃거리).

## 2. 브랜드

| 항목 | 내용 |
|---|---|
| 이름 | **CHARWELL** (차웰) — Char(통을 그을리는 불) + Well(켄터키 석회암 샘물) |
| 종류 | Kentucky Straight Bourbon Whiskey (가상) |
| 메인 카피 | **불에 그을린 통에서, 켄터키의 여름을 여덟 번.** |
| 영문 슬로건 | Born in fire. Kept by Kentucky. |
| 톤 | 묵직하고 따뜻함. 과장 없이 짧은 문장. 밤, 불빛, 나무 냄새. |
| 타깃 | 위스키에 막 관심이 생긴 25~35세. "버번은 독하고 어렵다"는 인상을 깨는 것이 목표 |

- CHARWELL은 포트폴리오용 **가상 브랜드**이며, 실제 브랜드명·로고·병 디자인을 쓰지 않는다.

## 3. 페이지 구성 (데스크톱 1440)

| # | 섹션 | 역할 | 내용 | 인터랙션 |
|---|---|---|---|---|
| 01 | **HERO** | 첫인상 | 어둠 속 병 하나, 아래에서 피어오르는 호박색 연기, 큰 제목 | WebGL 연기(호박색) + 커서가 지나가면 연기가 흩어짐 |
| 02 | **ORIGIN** | 이야기 | 버번이 만들어지는 4단계 | 섹션이 화면에 고정(sticky)되고, 스크롤하면 단계가 하나씩 넘어감 |
| 03 | **TASTING** | 맛 설명 | 향 · 맛 · 여운 + 맛 강도 막대 | 화면에 들어오면 막대가 채워짐 |
| 04 | **PAIRING** | 상상 | 숯불 고기 · 피칸파이 · 다크초콜릿 | 카드에 마우스를 올리면 사진 확대 + 설명 등장 |
| 05 | **COLLECTION** | 선택 | 3종 라인업 | 탭(병) 선택 시 이미지·정보 전환 |
| 06 | **FINALE** | 행동 | 한정판 출시 안내 + 버튼 + 연령 안내 + 음주 경고 | 버튼 마그네틱 효과 |

**02 ORIGIN — "Born in Fire"**
| 단계 | 제목 | 문장 |
|---|---|---|
| 01 | CORN | 옥수수 72%. 버번의 단맛은 여기서 시작됩니다. |

| 03 | CHAR | 새 오크통 안쪽을 불로 45초간 그을립니다. 바닐라와 캐러멜이 이 불에서 나옵니다. |
| 04 | RICKHOUSE | 뜨거운 여름에는 통이 숨을 들이쉬고, 겨울에는 내쉽니다. 여덟 번의 여름. |

**03 TASTING — "In the Glass"**

- 정보: 45% ABV (90 Proof) · 숙성 8년 · 700ml

**04 PAIRING — "By the Fire"**
| 카드 | 제목 | 문장 |

| 2 | 피칸파이 | 캐러멜과 견과류, 디저트 한 조각이 버번의 여운을 길게 만듭니다. |
| 3 | 다크초콜릿 | 쌉쌀한 카카오가 바닐라 향을 또렷하게 끌어올립니다. |

## 5. 반응형 (모바일 390)

- Figma에 **데스크톱 1440 + 모바일 390** 두 버전을 그린다.
- 모바일 원칙: 가로 배치 → 세로로 쌓기, 글자 최소 14px, 병 이미지는 화면 너비의 70%.
- 02 ORIGIN의 sticky 스크롤은 모바일에서 **세로로 이어지는 단계 목록**으로 바꾼다 (모바일 sticky는 끊기기 쉬움).
- 04 PAIRING의 호버 효과는 모바일에서 **처음부터 설명이 보이게** 한다 (터치에는 호버가 없음).

## 6. 이미지 계획

| 이미지 | 쓰는 곳 | 만드는 방법 |

| 병 정면 (누끼) | 01, 05 | Gemini로 라벨 없는 병 생성 → Photoshop에서 **라벨 직접 디자인 + 합성** (DAYLONG 방식) |

| 옥수수 · 샘물 · 숙성창고 | 02 | Gemini, 같은 톤 프리셋으로 보정 |
| 숯불 고기 · 피칸파이 · 다크초콜릿 + 잔 | 04 | Gemini, 어두운 배경 + 불빛 조명 통일 |

- 모든 사진에 **공통 Camera Raw 프리셋**(ROLL 36 방식)을 만들어 톤을 맞춘다.
- 출처는 `docs/charwell-credits.md`에 이미지마다 기록한다.

## 7. 구현 계획 (코드)

| 항목 | 내용 |
|---|---|
| 위치 | `charwell/index.html` — 포트폴리오와 분리된 독립 페이지 |
| 스타일 | `scss/charwell.scss` → `css/charwell.css` (기존 abstracts의 함수·mixin 재사용) |
| 레이아웃 | **Flex / Grid로 배치** (메인 페이지의 절대 좌표 방식은 쓰지 않음 → 반응형 가능) |
| 연기 | 기존 `js/marble.js`를 호박색 설정으로 재사용 |
| 스크롤 | IntersectionObserver(등장, 막대 채우기) + CSS `position: sticky`(02 ORIGIN) |
| 라이브러리 | 없음 (바닐라 JS 유지) |
| 접근성 | `prefers-reduced-motion`이면 연기·sticky 애니메이션을 끄고 정적 화면 |

5. **포트폴리오 연결** — 케이스 페이지, Works 카드 04, README 표 업데이트

## 9. 완료 기준

- 데스크톱과 휴대폰에서 **확대 없이 모든 글자를 읽을 수 있다.**
- 01 연기, 02 sticky, 03 막대, 05 탭 전환이 동작하고, 움직임 줄이기 설정에서도 내용이 다 보인다.
- 연령 안내와 음주 경고 문구, 가상 브랜드 표기가 들어가 있다.
- 배포 주소에서 `charwell/` 페이지와 케이스 페이지가 열린다.
