## 1. 배경과 목표

- 사람인 등 공고는 **패션·화장품 상세페이지**를 요구한다. PROJECT 02(DAYLONG, 화장품)에 이어 패션을 채운다.
- DAYLONG에서 느낀 점을 반영한다.
  - **스크롤이 길어서 지루했다** (1720×22,600, 11개 섹션) → 이번엔 **6개 섹션, 약 12,600px**로 압축한다.
  - 다른 디자이너 작업보다 **사진 톤과 콘셉트 장치가 약했다** → 필름 롤 콘셉트 하나로 페이지 전체를 묶고, 모든 사진 톤을 통일한다.
  - **자동 레이아웃을 마지막에만 썼다** → 처음부터 적극적으로 쓴다 (7번 참고).
- 이 프로젝트의 목표:
  1. 감성 화보(디자인형)와 정보 정리(실무형)를 **한 페이지에서** 보여 준다.
  2. DAYLONG(밝은 화이트·아쿠아)과 정반대인 **어두운 웜 톤**으로 표현 폭을 보여 준다.
  3. 포트폴리오 사이트에 케이스 스터디로 올린다.

### 성공 기준
- 지루하지 않게 끝까지 읽힌다: 사고 싶게 → 입은 모습 상상 → 확신 → 여운.
- 모든 사진이 같은 필름 톤으로 보인다.
- 정보 섹션(소재·사이즈·세탁)이 쇼핑몰 실무 수준으로 깔끔하다.
- 면접에서 Figma 원본의 컴포넌트·자동 레이아웃 구조를 보여 주며 설명할 수 있다.

### 레퍼런스 (무드만 참고)
- 필름 네거티브 콜라주 니트 상세페이지(사용자 스크린샷): 필름 테두리 장치, 거울 셀카, 얇은 세리프 대형 타이포
- 노매뉴얼: 빈티지·아날로그·무심한 남녀 공용 감성
- 해칭룸: 따뜻하고 포근한 니트 감성
- 레이아웃을 통째로 따라 하지 않는다. 필름 코드는 실제 필름 제품명(예: TX 5063)이 아닌 **ROLL 36 자체 코드**를 쓴다.

### 콘셉트
- **따뜻한 밤의 필름 롤**: 스탠드 불빛 아래 실내에서 찍은 필름 사진처럼.
- 화보 섹션은 어두운 웜 차콜, 정보 섹션은 크림. 배경이 **어둠 → 밝음 → 어둠**으로 바뀌며 리듬을 만든다.

### 필름 장치
- **필름 프레임**: 사진 + Film Black 테두리 + 위아래 가장자리 글자.
- **가장자리 글자 체계**:
  - 프레임 번호: `▶ 01A`, `▶ 02A` … (섹션 순서대로 이어서 매긴다)
  - 롤 코드: `R36 2611` (ROLL 36 + 26년 11월)
  - 롤 진행: `01/36` … `36/36` (마지막 섹션에서 36/36)
- 사진 톤: Photoshop Camera Raw 프리셋 **"ROLL36 tone"** 하나로 모든 사진에 같은 값을 적용한다.
  - 시작값: 색온도 +8, 채도 -15, 하이라이트 -20, 블랙 +15(살짝 뜬 검정), 그레인 25 / 크기 30 / 거칠기 50

## 6. 이미지 계획

### 공통 규칙
- 생성: Gemini / ChatGPT. 첫 이미지를 **기준 이미지**로 삼아 이후 생성 때 함께 첨부해 니트 디자인을 맞춘다.
- 구도: 착용 컷은 **거울 셀카(휴대폰이 얼굴을 가림)** 위주. 얼굴 일관성 문제를 피한다.
- 환경: 밤의 실내, 스탠드·간접조명, 따뜻한 빛, 나무 가구·러그 같은 포근한 공간.
- 니트 묘사 고정: "semi-oversized half-neck (mock neck) rib knit sweater, 2x2 ribbing, ribbed cuffs and hem".
- 실제 브랜드 로고, 실제 상품과 똑같은 디자인이 나오지 않게 한다.
- 모든 사진에 "ROLL36 tone" 프리셋을 적용한다.

## 7. Figma 구조 (자동 레이아웃 적극 활용)

### 컴포넌트
| 컴포넌트 | 구조 | 쓰는 곳 |
|---|---|---|
| **Film Frame** | 세로 자동 레이아웃: 위 가장자리 글자 줄 / 사진 / 아래 가장자리 글자 줄. 배경 Film Black, 패딩으로 테두리 두께 조절 | 01·02·03·06 |
| Caption | 가로 자동 레이아웃: Code 스타일 텍스트들 + 구분점 | 03 |
| Color Chip | 가로 자동 레이아웃: 원 + 컬러 이름 | 02 |
| Info Row | 가로 자동 레이아웃: 항목명(고정 폭) + 단계들 | 05 체크 표 |
| Size Row | 가로 자동 레이아웃: 칸 5개(채우기) | 05 사이즈표 |
| Care Item | 세로 자동 레이아웃: 아이콘 + 글자 | 05 세탁 |

- Film Frame의 사진은 **이미지 채우기(Fill)** 로 교체한다. 인스턴스마다 사진과 번호만 바꾼다.

### 섹션 프레임
- 섹션 프레임 = **세로 자동 레이아웃** (위아래 패딩, 요소 간격).
- 콜라주처럼 겹쳐야 하는 부분(01 타이포, 03 사진 겹침)은 자동 레이아웃 안에서 **절대 위치(Absolute position)** 로 빼서 자유롭게 놓는다.
- 전체 페이지 프레임 `ROLL36_상세페이지` (가로 1720) = 섹션 6개를 담은 세로 자동 레이아웃, 간격 0 → 섹션 높이를 바꾸면 아래 섹션이 자동으로 따라온다.
